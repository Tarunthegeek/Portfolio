# Tarun N - Portfolio

Static portfolio website for GitHub Pages.

## Publish

Create a public GitHub repository named `Tarunthegeek.github.io`, push this project to its `main` branch, then select **Settings > Pages > Deploy from a branch > main > /(root)**.

The default site address will be `https://Tarunthegeek.github.io/`. A custom domain can be connected later in **Settings > Pages** after registering it with a domain registrar.
